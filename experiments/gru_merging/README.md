# GRU merging and temporal interventions

In one cohort, 96 GRUs were trained, 21 strictly qualified at decision 512, and 210 dependent model pairs formed. Same-task parameter averaging damaged some qualified pairs. Output ensembles were a comparator, not demonstrations of complementary-skill composition.

A selected candidate-activation clamp (V6) restored a delayed signed donor effect on held-out histories. This was conditional on the artificial clamp and interval and did not restore the native strict memory task generally. Early mechanistic repair selection failed its comparator.
