# Experiment families (documentation indexes)

These folders are guides to the recorded research, **not reconstructed executable implementations**. The original code, checkpoints and numerical arrays are not part of this initial repository. Consult the [checkpoint manifest](../reproducibility/checkpoint_manifest.csv) before treating any result as reproducible here.

- [ANN robotics](ann_robotics/README.md): specialists, alignment, Homing action distillation and source problems.
- [Small NCA geometry](nca_geometry/README.md): exact coordinate controls, recurrent sensitivity and Hessian/Jacobian tests.
- [NCA memory](nca_memory/README.md): delay qualification, selected saddle-node case and cellular coupling.
- [GRU merging](gru_merging/README.md): independent parents, same-task merge failures and V6 interventions.
- [Causal distillation](causal_distillation/README.md): output imitation, first-order fold shifts and OOD horizon tests.
