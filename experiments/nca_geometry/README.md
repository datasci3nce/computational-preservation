# Small NCA geometry

Study of loss, exact symmetries, Hessian structure, and finite-time Jacobian propagation in small recurrent models. A selected matched/mismatched pair had similar task losses yet strongly different state perturbation amplification. Later OOD work did **not** establish predictive superiority of the more complex features for task outcomes.

**Required source:** archived code and arrays defining the exact nominal task, parameter matching rule and perturbation norms. No such executable assets are included here.
