# NCA memory and selected fold mechanism

The selected seven-cell/two-hidden-channel system uses three internal recurrent microsteps per decision. Exact global hidden-basis `O(2)` is a coordinate control, not physical equivariance. Natural signed-cue histories traverse a slow region near a saddle-node fold on a restricted path between two merged model variants.

The [complete technical note](../../paper/nca_fold_case_study/RESEARCH_NOTE.md) contains the equation, the local passage-time account and the negative controls. Strong binary signed recall did **not** imply strict three-way retention; ordinary task gradients matched fold-directed edits and fixed cue-independent forcing could mimic a selected neighbor-edge cut.
