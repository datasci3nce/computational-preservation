## Positioning the NCA result

The strongest potentially useful contribution is **an empirically constrained selected-case chain**: merger-derived parameter changes; local fold geometry; a derivative-derived quantitative passage-time prediction; parameter, state and coupling perturbations; and controls which refute overstrong interpretations. The novelty, if publishable, lies in how these pieces test one specified learned recurrent system, *not* in discovering a new mathematical normal form.

A central confound is already known: the source interpolation connects two **merger-derived** parameterizations, not independently qualified parent models. The case therefore illustrates a model-modification mechanism rather than demonstrating that qualified skill composition necessarily fails this way.

## Positioning GRU results

The GRU cohort gives stronger evidence that averaging independently competent parents can damage an established same-task capability. But the selected candidate clamp is a different diagnostic and **does not replicate the NCA fold mechanism**. The repair-selector failure is a valuable negative result: dynamical understanding must still demonstrate extra *decision value* in prospective selection tests.

## Positioning distillation

Teacher output matching changes weights through a particular architecture, loss, optimizer, initialization and observation schedule. It does not uniquely invert the mechanism. Known parameter changes can be analyzed with dynamical sensitivity; that is **forward model analysis**, not blind identification from outputs. The t512→t1024 drop specifically motivates stronger horizon-generalization tests.

## How to extend the review

Before publication, search systematically for mechanistic analyses of RNN memory, saddle-node transients and ghost points; model-merge diagnostics under controlled qualification; causal abstraction and patching reliability; horizon-limited imitation learning and distillation; and dynamical forecasting on new interventions. Record an inclusion table, exact versions and contrasting negative results. Do not base a novelty claim on the number of combined keywords or techniques.
